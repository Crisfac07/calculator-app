# AI Usage

AI tools were used as a development aid throughout the project, mainly for
code review, testing, troubleshooting, and documentation.

The implementation and technical decisions were reviewed and validated
manually. AI suggestions were evaluated individually and only applied
when they were appropriate for the project.

## Examples of AI Assistance

### Code Review

AI was used to review code for readability, maintainability, and
idiomatic practices.

Example prompt:

> Review this code as a senior software engineer. Identify potential
> issues, unnecessary complexity, and improvements while keeping the
> solution simple and appropriate for a small project.

### Unit Tests

AI was used to identify relevant test cases and edge cases for the
calculator operations and expression evaluator.

Example prompt:

> Review this calculator implementation and suggest important unit
> tests and edge cases that should be covered.

### Troubleshooting

AI was used to help understand development errors and investigate
possible causes.

Example prompt:

> Explain this error, identify the likely cause, and suggest the
> simplest appropriate fix.

### Documentation

AI was used to help review and improve the project's documentation,
including setup instructions, API documentation, project structure,
technical decisions, and testing instructions.

Example prompt:

> Review this README point by point and identify missing, unclear, or
> unnecessary information. Suggest improvements while keeping the
> documentation concise and appropriate for the project.

All documentation suggestions were reviewed individually and validated
against the actual project before being incorporated.
